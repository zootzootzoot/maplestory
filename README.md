# Maple Compass

A free overlay guide for MapleStory Classic World: where to train for your build, what your quests still
need and where to get it, what your loot is worth, and the way to anywhere, drawn on the game's own Mini Map.

**Download:** [the latest release](https://github.com/zootzootzoot/maplestory/releases/latest) (Windows 10/11) ·
site: https://zootzootzoot.github.io/maplestory

It only looks at the screen. It never reads or changes game memory or files, and never presses keys or clicks.
Unofficial fan project, not affiliated with or endorsed by NEXON. This is an early alpha.

Prices from [maplestory.market](https://maplestory.market/?ref=ybbmvag5) (with your own free key, set in Settings)
or the maplestory-classic.com public feed. Drop data: MapleClassic Wiki community (CC BY-NC-SA 4.0).
